# Extensive Python & PyTorch for AI - V3

> An advanced Python course for a fundamental, deep-dive understanding of the Python Language and PyTorch. Designed for those who want to become software and application architects. **This course is not for beginners.**

---

## 🎯 About the Course

This repository contains the advanced modules, code examples, and materials for **Extensive Python & PyTorch for AI - V3**. It goes beyond standard syntax, diving deep into Python's internals, memory management, functional programming paradigms, advanced data structures, and asynchronous patterns essential for high-performance AI systems and enterprise architecture.

---

## 📚 Course Curriculum

### 🔹 PHASE #1 - Functional Python

The first phase establishes an elite foundation in advanced Python mechanics:

* **Basics & Type Hierarchy**: Python Type Hierarchy, multi-line statements, variable names, conditionals, functions, while loops, try/except/finally blocks, for loops, and classes.
* **Object Mutability & Interning**: Variables and memory references, garbage collection, dynamic vs. static typing, variable re-assignment, object mutability, variable equality, and Python interning.
* **Numeric Types I & II**: Integers, constructors, bases, rational numbers, floats, rounding, coercing types, decimals (operations & performance), complex numbers, and boolean logic/precedence.
* **Functional Parameters**: Arguments vs. parameters, positional/keyword arguments, unpacking iterables, extended unpacking (`*args`, `**kwargs`), and parameter defaults.
* **First-Class Functions (Part I & II)**: Lambda expressions, sorting with lambdas, functional introspection, callables, map, filter, zip, list comprehensions, reducing functions, partial functions, operator module, docstrings, and annotations.
* **Scopes & Closures**: Global/local scopes, nonlocal scopes, closures, and practical applications.
* **Decorators**: Decorator patterns and applications (timers, loggers, stacked decorators, memoization, classes, and dispatching).
* **Tuples & Named Tuples**: Tuples as data structures, named tuples, docstrings, and applications.
* **Modules, Packages & Namespaces**: Python imports, importlib, import variants, reloading modules, `__main__`, structuring packages, and namespaces.
* **f-Strings, Timing & CLI Arguments**: Dictionary ordering, kwargs, tuples, high-resolution timing functions, and command-line argument parsing.
* **Sequence Types (I & II) & Advanced Comprehensions**: Mutable vs. immutable sequences, index bases, slice bounds, copying, custom sequences, in-place concatenation, repetition, sorting, and small projects.
* **Iterables & Iterators**: Iterating collections, cyclic iterators, built-in iterators, the `iter()` function, and iterator applications.
* **Generators & Iteration Tools**: Generator functions (`yield`), generator expressions, `yield from`, aggregators, chaining, teeing, and zipping.
* **Context Managers**: Custom context managers, lazy iterators, generators as context managers, and nested applications.
* **Coroutines & Data Pipelines**: Coroutines, generator states, exception handling, and building robust data pipelines.
